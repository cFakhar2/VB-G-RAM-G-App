# VB-G RAM G: Interim Permissible Works Explorer

An interactive, responsive web application designed to explore and navigate the interim list of permissible works under the **Viksit Bharat-Guarantee for Rozgar and Ajeevika Mission (Gramin) (VB-G RAM G) Act, 2025**.

## 🚀 Overview

The **VB-G RAM G Act, 2025** (effective July 1, 2026) represents a significant shift in rural development strategy, focusing on sustainable asset creation across four key pillars:
- **Water Security**
- **Core Rural Infrastructure**
- **Rural Livelihood**
- **Disaster Mitigation**

This explorer tool provides a structured interface to browse all 318 proposed works, helping stakeholders, panchayats, and citizens understand the scope of the mission.

## ✨ Features

- **Hierarchical Navigation**: Easily browse through the 4 Major Categories and 29 Sub-categories.
- **Global & Local Search**: Robust search functionality to find specific schemes or types of work (e.g., "Community", "Masonry", "Irrigation") across the entire database.
- **Detailed Insights**: Detailed side-panel for each work item including implementation guidelines, target audience (Individual/Community), and hierarchical context.
- **AI Overview**: Integrated AI-summarized overview of the Act's vision, features, and focus areas.
- **Adaptive UI**: High-contrast Light and Dark modes for better accessibility in different environments.
- **Mobile Responsive**: Fully optimized for use on smartphones and tablets for field use.

## 📥 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/cFakhar2/VB-G-RAM-G-App.git
   cd VB-G-RAM-G-App
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
